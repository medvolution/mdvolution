# Medvolution website

Static bilingual website for Medvolution, deployed with GitHub Pages.

## Structure

- `index.html`: site entry (language selection, pending)
- `CNAME`: custom domain (mdvolution.com)
- `css/`, `js/`, `img/`, `video/`: site assets
- `.github/workflows/static.yml`: deployment to GitHub Pages from `main`
